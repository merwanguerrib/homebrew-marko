# Homebrew tap for Marko

Marko is a Markdown editor for macOS (Apple silicon, macOS 12 or later). Website: https://marko.md

```sh
brew trust merwanguerrib/marko
brew install --cask merwanguerrib/marko/marko
```

Recent Homebrew versions ask you to trust a third-party tap before loading it, hence the first command.
